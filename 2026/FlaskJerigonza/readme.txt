How to run this

    Install Flask: Open your terminal and run pip install flask flask-cors.

    Start the API: Run the Python script (python app.py). You’ll see a message saying it's running on [http://127.0.0.1:5000](http://127.0.0.1:5000).

    Open the HTML: Simply double-click the index.html file in your browser.
