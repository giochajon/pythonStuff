How to run this

    Install Flask: Open your terminal and run pip install flask flask-cors.

    Start the API: Run the Python script (python app.py). You’ll see a message saying it's running on [http://127.0.0.1:5000](http://127.0.0.1:5000).

    Open the HTML: Simply double-click the index.html file in your browser.


    remember to activate the environment

    source ./gioflask/bin/activate



# ---------------- node js version 
To run this backend application, make sure you have Node.js installed on your machine. Follow these steps:
Step 1: Initialize the Project

Open your terminal or command prompt in the folder where you want to keep your project, and initialize a new Node.js project:
Bash

npm init -y

Step 2: Install Dependencies

Install Express (the web framework) and CORS (to allow cross-origin requests from your HTML file):
Bash

npm install express cors

Step 3: Run the Server

Launch your application by running:
Bash

node server.js

You should see the message: Jerigonza API is running on http://127.0.0.1:5000
Step 4: Test with index.htm

    Double-click or open your index.htm file in any web browser.

    Type a phrase (e.g., esta es una prueba) into the text box and click Translate.

    The interface will connect to your local Node.js API and display the result: Result: efestafa ess ufunafa prufuefebafa.
